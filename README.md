# 오로라 (AURORA) 제조 운영 지능화 상용 서비스 플랫폼

> **금속 차폐 산업설비의 제조데이터 기반 AI 예지보전·정비 자동화 시스템**  
> 써니웨이브텍 사업 확장 제안 · 반도체 & OLED 제조 운영 지능화 서비스

---

## 1. 프로젝트 개요

본 프로젝트는 써니웨이브텍의 **금속 표면파 통신 기술**을 기반으로, 무선 차폐 환경에서 신뢰성 있게 수집된 현장 제조 데이터를 산업용 AI와 결합하여 다음의 6대 핵심 모듈을 제공하는 완성형 상용 웹 플랫폼입니다. **(모든 사용자 인터페이스 및 화면 안내 메시지 100% 한글화 적용)**

1. **2D 설비 관제 (메인 관제 센터)**: 10대 반도체/OLED 공정 설비의 정밀 2D SVG 벡터 일러스트레이션, 제품 이송 레일, 실시간 센서 데이터 버스 및 로트/패킷 이동 애니메이션
2. **연간 시뮬레이터**: 2027년 365일 타임라인 기반 1일/초(기본), 5배속, 30배속 가속 시뮬레이션 및 과거 날짜 스냅샷 재현
3. **전문 AI 분석실**: 4대 ML 회귀 모델(의사결정나무, 랜덤포레스트, 엑스트라트리, 그래디언트부스팅) 및 가중 앙상블 비교 평가, 특성 중요도 분석, 역할별(작업자/관리자/임원) 4문장 쉬운 해석, 다목적 최적 파라미터 탐색 샌드박스
4. **정비 협업 및 현장 표준행동절차(SOP) 워크플로우**: 경보 감지부터 작업지시(P0 긴급/P1 점검/P2 계획) 발행, 승인, 수행, 품질 검증까지의 상태 추적 및 비상 안전 SOP 가이드
5. **보고서 스튜디오**: 5종 정형 보고서(양식 1호~5호) 템플릿, 3개 독자 모드 동적 적응, 블록형 A4 인쇄 레이아웃(`@media print` 완비) 및 CSV 데이터 파일 다운로드
6. **현장 도구함**: 사업장 연속 무재해 달성 일수 카운터, 주요 안전 공지사항 원장, 공학 단위 환산기(압력, 온도, 에너지, 유량), 공학용 계산기

    ├── index.html                    # 메인 통합 웹 인터페이스 (전면 한글화)
    ├── sim.css                       # 인더스트리얼 다크/라이트 디자인 시스템 스타일시트
    ├── sim.js                        # 관제 시뮬레이션, AI 추론 엔진, 워크플로우 로직 (전면 한글화)
    ├── equipment.js                  # 10대 공정 설비 2D 정밀 벡터 SVG 정의
    └── model_metrics.json            # 4대 모델 + 가중 앙상블 공식 검증 메트릭스 (한글 메타데이터)

## 3. 프로그램 실행 방법

### 방법 A. 내장 로컬 웹 서버 실행 (권장)
터미널에서 아래 명령을 실행합니다:
```bash
python3 server.py
```
서버 기동 후 웹 브라우저에서 아래 주소로 접속합니다:
👉 **`http://localhost:8000/dist/index.html`** (또는 `http://localhost:8000/`)

### 방법 B. 브라우저에서 직접 파일 열기 (서버 불필요)
`dist/index.html` 파일을 웹 브라우저(Chrome, Edge, Safari 등)로 더블 클릭하여 바로 실행할 수 있습니다.
